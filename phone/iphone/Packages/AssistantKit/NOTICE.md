# Client snapshot

The `PhoneGatewayClient` target (named `AbstractGatewayClient` until 0.16.0) and its wire-format tests derive from the MIT-licensed
AbstractAssistant Apple Watch client. See `WATCH_SNAPSHOT.json` for original source hashes
and [the repository license](../../../../LICENSE).

This is a phone-owned snapshot. Do not edit `watch/` to change the iPhone app. Reconcile
upstream changes deliberately and update the provenance record when importing them.
