# AbstractAssistant on phones

Native phone clients for your AbstractGateway.

- [iPhone](iphone/README.md) — SwiftUI app for iOS 26 and later.

Each platform has its own application, build outputs and resources. Gateway execution and
durable conversations stay on the server. The iPhone app carries the
[Apple Watch app](../watch/apple/README.md) as its companion: one product, one project
(`iphone/project.yml`), one version; the watch sources live in `../watch/apple`.
