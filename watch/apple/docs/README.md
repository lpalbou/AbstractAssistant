Start with the [README](../README.md) for what the app does and how to sign in. These pages go
deeper:

- [architecture.md](architecture.md) — the components, the gateway call behind each screen,
  background behaviour and security. Read it before changing how the watch talks to the gateway.
- [pairing.md](pairing.md) — pairing a physical watch with your Mac for development.
- [../BUILD.md](../BUILD.md) — building, testing, running in the simulator and on a watch, and App
  Store packaging.
- [../CHANGELOG.md](../CHANGELOG.md) — the release history of the watch app.
